# Energigas Facturador Web

Interfaz Angular 22 para documentos de ventas y carga masiva.

## Estructura

```text
src/facturador-web/  Proyecto Angular
docs/                Operación y estado del proyecto
```

## Inicio local

1. Instala dependencias:

   ```powershell
   pnpm --dir src/facturador-web install --frozen-lockfile
   ```

2. Inicia la aplicación:

   ```powershell
   pnpm --dir src/facturador-web start
   ```

3. Abre `http://127.0.0.1:4200`.

La API debe estar disponible en `http://localhost:5000/api`.
